# SESIVERSO — Caverna do Tempo 360° v10

Versão revisada da experiência imersiva em 360°.

## Alterações desta versão
- novo panorama principal de entrada, mais aberto e com maior sensação de 360°;
- campo de visão inicial ampliado para mostrar mais do ambiente;
- logo oficial do SESI no cabeçalho;
- desenho/cartoon da tocha removido da interface;
- som ambiente local em loop, sem depender de internet;
- botão **Ficha** para fechar e reabrir a última ficha arqueológica quando quiser;
- ateliê rupestre não abre sozinho;
- desenhos predefinidos do ateliê agora são inseridos ao clicar no botão e também podem ser posicionados clicando na tela;
- carimbos: mão, bisão, cervo, caçador e espiral;
- indicação de WASD removida da interface;
- mapa redesenhado para acompanhar a sequência das 9 galerias;
- panoramas com nomes/cache v10 para evitar carregamento das imagens antigas;
- PWA atualizado para cache `v10-panorama-audio`.

## Publicar no GitHub Pages
Substitua todos os arquivos do repositório por esta versão. Depois do deploy, faça `Ctrl + F5` uma vez. Em celular/PWA instalado, feche e reabra o app após o primeiro carregamento da nova versão.
